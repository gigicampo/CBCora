# CBCora Prototype v0.5

CBCora is a mobile-first CBC companion prototype.

## Included in this build
- Splash/title page and maroon/light-red/white branding
- Responsive phone/tablet layout
- Personal profile with optional photo
- CBC result explanations and guidance previews
- Realistic food/activity guidance visuals
- Last-five-test trend cards for all included CBC measures on Home
- Full trend view and result history
- Side-by-side comparison of any two saved CBC reports
- Print / Save as PDF CBC summary workflow
- OCR-ready upload pipeline with simulated extraction confidence scores and mandatory manual review

## OCR note
This prototype does not claim to perform production-grade OCR. The interface and data-validation flow are ready for a real OCR provider to be connected later. The review screen is intentionally mandatory because CBC report formats, units and reference ranges differ between laboratories.

## Medical note
CBCora is educational. It does not diagnose conditions, prescribe treatment, or replace a healthcare professional.
